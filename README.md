# Be Color 講師ページ

STUDIO で作っていた https://teachers.becolor.jp/ を、
**スプレッドシートで中身を管理 → GAS がパスワード確認してデータを返す → GitHub Pages で表示** する形に移行したもの。

```
スプレッドシート（skill.hack.school@gmail.com のドライブ）
  └ GAS ウェブアプリ … パスワードが正しいときだけシートの内容を返す
        ▲ fetch（パスワード付き）
GitHub Pages（docs/）… デザイン（HTML/CSS/JS）だけ。中身のデータは含まない
```

| フォルダ | 中身 |
|---|---|
| `docs/` | 公開サイト（GitHub Pages で配信） |
| `gas/Code.gs` | スプレッドシートに入れる GAS |
| `gas/Seed.gs` | STUDIO から移した初期データ。**公開リポジトリには入れない**（.gitignore 済） |
| `tools/build_preview.py` | 初期データ入りの確認用 `preview.html` を作る |

---

## セットアップ手順

### 1. スプレッドシートと GAS（skill.hack.school@gmail.com でログインして作業）
1. ドライブで新しいスプレッドシートを作る（例：「BeColor 講師ページ管理」）
2. 拡張機能 → Apps Script を開く
3. `コード.gs` の中身を全部消し、`gas/貼り付け用_まとめ.gs`（Code.gs と Seed.gs を1つにしたもの）を貼って保存
4. 関数 `setupSheets` を選んで ▶実行（初回は権限の許可が出るので許可）
   → 「設定」「講師」シートが移行データ入りで作られる
5. スプレッドシートを開き直すと、メニューに「サイト管理」が出る
6. 「サイト管理 → STUDIOの画像をドライブに移す」を実行
   → 画像がドライブの「BeColor生徒ページ_画像（講師用と共通）」フォルダに保存され、URL が置き換わる
7. Apps Script 右上「デプロイ → 新しいデプロイ → 種類：ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 表示された URL（`https://script.google.com/macros/s/…/exec`）を控える

### 2. GitHub Pages
1. `docs/config.js` の `GAS_URL` に上の URL を貼る
2. GitHub にリポジトリを作って push
3. Settings → Pages → Branch: `main` / フォルダ: `/docs` → Save
4. 独自ドメイン（teachers.becolor.jp）を使う場合は Pages の Custom domain に入力し、DNS の CNAME を `<ユーザー名>.github.io` に向ける

> GAS のコードを変更したときは「デプロイを管理 → 編集 → バージョン：新バージョン」で更新する（URL は変わらない）。

## スプレッドシートの使い方

### 設定シート
パスワード・説明文・ロゴ画像など。パスワードを変えると、ログイン中の人も次回アクセス時に再入力になる。

### 講師シート（1行 = 1パーツ、上から順に表示）
設定シートの「トップページ」に書いたシート（講師）が、そのままトップに表示される。

| 列 | 内容 |
|---|---|
| 表示 | チェックを外すと非表示（行を消さずに一時的に隠せる） |
| 種類 | 見出し / ボタン / 開閉 / 画像カード / LINEボタン / 枠ボタン / 文章 |
| 開閉の中 | チェックすると、すぐ上の「開閉」の中に入る |
| タイトル | セル内改行（Mac：⌘+Enter／Windows：Alt+Enter）で2行にできる |
| サブタイトル | ボタンの下の小さい文字（例：(アクティブクラス)） |
| リンクURL | 押したときに開くページ（空欄ならリンクなしのボタン） |
| 画像URL | ドライブの共有リンクをそのまま貼れば OK |
| 画像比率 | 16:9 / 3:2 / 4:3 / 1:1 / 4:5 など。比率は固定で、はみ出た部分は切り抜かれる |
| 色 | 赤 / オレンジ / 黄 / 緑 / 青 / 紫 / 青紫。見出しに付けた色が、次の見出しまでのボタンに引き継がれる。行ごとに上書きも可 |
| メモ | サイトには出ない |

### 画像の入れ替え
1. 画像をドライブにアップロード
2. 共有 →「リンクを知っている全員」が閲覧可にする
3. 共有リンクをコピーして `画像URL` に貼る → 次にページを開いたときに反映

### 反映タイミング
シートを編集すると自動でキャッシュが消え、次にページを開いた（再読み込みした）ときに最新になる。
反映されないときは「サイト管理 → サイトに今すぐ反映」。
